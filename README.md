# Week 4 - Java I/O and Exception Handling

## Internship Project
Engineer - Java Development

## Overview
This repository contains Java programs developed during Week 4 of the internship. It focuses on File Input/Output operations and Exception Handling.

## Topics Covered
- File Writing
- File Reading
- File Updating and Appending
- File Deletion
- Checked Exceptions
- Unchecked Exceptions
- Try-Catch
- Try-With-Resources
- Complete File Processing Application

## Programs

1. 01-FileWrite - Writing data into a file.
2. 02-FileRead - Reading data from a file.
3. 03-FileUpdate - Appending new data to an existing file.
4. 04-FileDelete - Deleting a file.
5. 05-CheckedException - Handling checked exceptions.
6. 06-UncheckedException - Handling unchecked exceptions.
7. 07-FileProcessing - Complete file processing application.

## Technologies Used
- Java
- Java I/O
- Exception Handling
- File Handling

## Learning Outcomes
Learned how to create, read, update, and delete files using Java. Also understood checked and unchecked exceptions, try-catch blocks, and resource management using try-with-resources.
